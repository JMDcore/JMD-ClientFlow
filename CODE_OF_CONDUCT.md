# Código de conducta

Este proyecto busca mantener una comunidad profesional, abierta y respetuosa.

## Comportamiento esperado

- Comunicar ideas y desacuerdos con respeto.
- Aportar críticas concretas y orientadas a mejorar el proyecto.
- Respetar la privacidad y no compartir información personal de terceros.
- Mantener issues y pull requests centrados en aspectos técnicos o de producto.

No se tolerarán ataques personales, acoso, discriminación, amenazas ni contenido deliberadamente disruptivo.

## Aplicación

Los incidentes pueden comunicarse de forma privada a `jmdcore.dev@gmail.com`. El mantenedor podrá editar, ocultar o eliminar contenido y restringir la participación cuando sea necesario.
