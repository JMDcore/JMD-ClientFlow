# Política de seguridad

## Versiones soportadas

El proyecto se encuentra en fase MVP. Solo la última versión de la rama `main` recibe correcciones de seguridad.

## Reportar una vulnerabilidad

No publiques vulnerabilidades en un issue abierto. Envía una descripción a `jmdcore.dev@gmail.com` incluyendo:

- componente o flujo afectado;
- pasos mínimos para reproducirlo;
- impacto esperado;
- posible mitigación, si la conoces.

Se confirmará la recepción y se evaluará el alcance antes de publicar información técnica. No incluyas datos personales, credenciales ni secretos en el reporte.

## Alcance actual

ClientFlow utiliza datos de demostración y persistencia local. No dispone de autenticación, API pública ni almacenamiento remoto en esta versión.
